\subsection{Environment specification}
\label{sec:pm-jax-envspec}

The platform trains on one environment: the large PointMaze with the reset noise switched off.
Every episode begins at exactly the same point and aims at exactly the same goal, so two copies
that differ only by their policy sampling see the same task, and a difference between two
configurations is not a difference between two randomly drawn start positions.
\Cref{tab:pm-jax-env} states it knob by knob.

\subsection{Train run 1.1: the first algorithm batch}
\label{sec:pm-jax-run11}

Four algorithm arms run at once: random network distillation, no exploration bonus at all, and the
two oracle visit-count bonuses that differ only in how fast their bonus falls with the count. Each
arm is swept over three learning rates, and each arm that has a bonus is swept over eleven weights
on that bonus.

\paragraph{Hypotheses.}
\begin{enumerate}[label=\textbf{H\arabic*},leftmargin=*,labelsep=0.6em]
\item \textbf{Random network distillation beats no exploration bonus.} At every one of the three
  learning rates, \texttt{rnd\allowbreak\_next\allowbreak\_state} at its best intrinsic weight
  reaches a higher maze-cell coverage and a higher whole-run reward than
  \texttt{no\allowbreak\_exploration} at the same learning rate.
\item \textbf{The oracle bonuses bound random network distillation from above.} The visit-count
  arms are given the true novelty signal that random network distillation has to estimate from a
  predictor's error, so at their best intrinsic weight they reach at least the coverage and reward
  that the best random-network-distillation configuration reaches.
\item \textbf{The two decays trade coverage against reward differently.} $1/\sqrt{n}$ keeps paying
  for a state long after $1/n$ has stopped, so the $1/\sqrt{n}$ arm reaches the higher coverage and
  the $1/n$ arm reaches the higher reward once the goal has been found.
\item \textbf{Reward against intrinsic weight is single-peaked.} For every bonus arm, whole-run
  reward as a function of the intrinsic weight rises and then falls: a weight far below the peak
  leaves the agent exploring too little to find the goal, and a weight far above it drowns the
  sparse extrinsic reward in the bonus, so the agent keeps chasing novelty after the goal is known.
\end{enumerate}

\paragraph{How to read the metrics tables.}
Define a \emph{configuration} as one (learning rate, intrinsic weight) cell of one algorithm arm,
and define $C$ as the number of copies it is given, $C = 256$ here; index the copies by
$k = 1, \dots, C$. Define $E_k$ as the number of episodes copy $k$ finishes within its $10^{7}$
environment steps, and $R_{k,e}$ as the extrinsic return of its episode $e$ --- the sum of that
episode's sparse rewards, which is the number of steps the copy spent inside the goal radius,
because the task is continuing and the episode is not ended by reaching the goal. Define $O$ as
the number of open cells of the maze map, $O = 46$ for the large map. Every table cell is the mean
over the configuration's completed copies plus or minus its standard error; $N$ is how many
completed copies that mean is taken over.

\begin{itemize}[leftmargin=*]
\item \textbf{Whole-run reward} (higher is better; the column the table is sorted by) --- copy
  $k$'s mean episode return over its whole run,
  $\bar{R}_k = \dfrac{1}{E_k} \sum_{e=1}^{E_k} R_{k,e}$.
\item \textbf{Last-100 reward} (higher is better) --- the same mean over that copy's last
  $\min(100, E_k)$ episodes, $\bar{R}^{\,100}_k = \dfrac{1}{\min(100, E_k)}
  \sum_{e = E_k - \min(100, E_k) + 1}^{E_k} R_{k,e}$. It separates a configuration that ends its
  run at the goal from one that reached the goal early and then wandered off.
\item \textbf{Success rate} (higher is better) --- the fraction of the configuration's copies that
  reached the goal at least once, $s = \dfrac{1}{C} \sum_{k=1}^{C} \mathbf{1}\!\left[\sum_{e=1}^{E_k}
  R_{k,e} > 0\right]$. A copy that never enters the goal radius collects exactly zero, because
  reaching the goal is the only thing this environment pays for.
\item \textbf{Maze-cell coverage \%} (higher is better) --- define $V_k$ as the number of distinct
  open maze cells copy $k$ has entered at least once over its whole run; the metric is
  $c_k = 100 \times \dfrac{V_k}{O}$.
\item \textbf{Steps to goal} (lower is better) --- define $S_k$ as the set of copy $k$'s episodes
  that reach the goal, and $g_{k,e}$ as the index of the first step of episode $e$ that earns
  reward $1$. The metric is $\bar{g}_k = \dfrac{1}{|S_k|} \sum_{e \in S_k} g_{k,e}$, the mean over
  successful episodes only. When fewer than $N$ copies have any successful episode, the cell
  prints how many it was averaged over.
\end{itemize}
